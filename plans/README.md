## Findings considered and rejected

- **Webhook URL exposed in client code** (`components/ChatWidget.tsx:16-17`): Not a performance issue. Relevant to security, not the user's specified focus (speed/smoothness/UX).
- **Console.log/warn in production code**: LOW impact; excluded because the effort to guard each one behind `process.env.NODE_ENV` produces negligible real-world performance gain. A planned cleanup could be a future task.
- **No `.env.example` file**: DX issue, not performance. Not in scope for this audit.
- **`@import` for Inter font in CSS**: This is a genuine minor perf issue but switching to `next/font` would change how Inter is loaded. Given the font is only used as a secondary option (not the default), the impact is minimal. Skipped in favor of higher-leverage items.
- **Gallery SeeMoreButton passes all images upfront (finding #6)**: Valid finding but lower impact than the top 5. The image metadata is small JSON (~3KB for all 16 images). Punting to avoid scope creep.
- **No image variant generation during build (finding #7)**: Addressed by Plan 001's approach (downscale originals directly, which is simpler and more effective than a build-pipeline variant system).
